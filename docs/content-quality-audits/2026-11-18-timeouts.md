## Claim and example evidence

1. **Scope:** A connect-only timeout cannot bound body-read duration. Read/idle semantics differ by HTTP client; some APIs combine DNS, TLS and other phases, so the article no longer implies that separate options always exist. AWS Builders' Library discusses coverage gaps and false timeouts.
2. **Deadline versus SLO:** The user latency SLO is an aggregate objective, not automatically a hard per-request stop time. The constructed 1-second scenario explicitly states a separately chosen 1-second useful deadline; it is not a real production incident. Failure impact depends on concurrency and resource pools, not a guaranteed outage.
3. **gRPC propagation:** Official gRPC Deadlines guidance says **no client deadline by default**; automatic parent-deadline propagation varies by implementation (Java/Go enabled by default, C++ requires explicit enabling). Propagation subtracts elapsed time and converts to a timeout to mitigate clock skew. Both locales were corrected.
4. **Cooperative cancellation:** Official gRPC Cancellation guidance says handler-side application work must observe the cancellation signal, and child-RPC cancellation behavior varies by implementation. This signal does not roll back committed external effects. Kept the link to Partial Failure and Idempotency distinct.
5. **Arithmetic and diagrams:** Traced the hypothetical flow `900 - 180 = 720` ms and `720 - 260 = 460` ms. For the self-check, `300 - 60 = 240` ms is a *maximum before additional safety margin*, not permission to send a new 500-ms child call. Fan-out branches share the same end-to-end deadline; required versus optional branch behavior is policy-specific.
6. **Evidence and operations:** Recorded stage-specific DNS/connect/TLS/write/header/read versus overall timeouts, false-timeout percentile trade-offs, latency distributions, queue/pool saturation and deadline/cancellation traces; no measured performance numbers or live fault-injection were asserted. Mermaid/pseudocode were inspected semantically; no real gRPC server was executed.
