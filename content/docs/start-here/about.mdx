Software Development Atlas is the personal learning and reference system of **Tran Trong Thuc** ([@thucne](https://github.com/thucne)).

I use the Atlas to turn software-engineering topics I study into material that is easier to revisit, verify, connect, and reason from later. It is intentionally more than a notebook: important topics can include source-backed explanations, diagrams, decision guides, architecture walkthroughs, and interactive teaching tools when those improve understanding.

## What the freshness signals mean

Every normal Atlas page carries a freshness classification, a `lastVerified` date, and a review target. The page header turns those fields into a visible freshness indicator.

A page that is **current** is still inside its review window. A page that is **due soon** is approaching the end of that window. A page marked **verification overdue** has passed its review target and should be re-checked before relying on details that may have changed.

An overdue review does **not** automatically mean the lesson is wrong. It means the Atlas no longer has recent verification evidence for that page.

The separate **Atlas last updated** date is a site-level maintenance marker. It is not a substitute for each lesson's own verification date.

## Corrections and improvements

The Atlas is Git-backed. Each lesson exposes an **Edit on GitHub** action so corrections, clearer explanations, source updates, and maintenance work can start from the canonical MDX file.
